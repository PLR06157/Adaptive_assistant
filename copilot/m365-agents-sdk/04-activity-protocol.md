# Activity Protocol

The Activity protocol is Microsoft's standard communication protocol used across Microsoft SDKs, services, and clients including Microsoft 365 Copilot, Microsoft Copilot Studio, and the Microsoft 365 Agents SDK.

---

## What is an Activity?

An `Activity` is a structured JSON object representing any interaction between a user and an agent:

- Text-based messages
- Events (user joining/leaving)
- Typing indicators
- File uploads
- Card actions
- Custom events

Every activity includes metadata about who sent it, who should receive it, the conversation context, the channel it originated from, the type of interaction, and the payload data.

### Activity Schema — Key Properties

| Property | Description |
|----------|-------------|
| `Id` | Typically generated by the channel if originating from a channel |
| `Type` | Controls the meaning of an activity (e.g., message type) |
| `ChannelID` | References the channel the activity originated from (e.g., `msteams`) |
| `From` | The sender of the activity (user or agent) |
| `Recipient` | The intended recipient of the activity |
| `Text` | The text content of the message |
| `Attachment` | Rich content like cards, images, or files |

**Full spec:** [Activity protocol specification](https://github.com/microsoft/Agents/blob/main/specs/activity/protocol-activity.md)

## Turns and TurnContext

### What is a Turn?

A _turn_ is the round trip of a message from client to your code and back:

1. **Incoming Activity** — User sends a message or performs an action
2. **Processing** — Agent receives and processes the activity via `TurnContext`
3. **Response** — Agent sends one or more activities back
4. **Completion** — Turn ends and `TurnContext` is disposed of

### Accessing TurnContext Data

```csharp
var messageText = turnContext.Activity.Text;
var channelID = turnContext.Activity.ChannelId;
```

### TurnContext Key Properties

| Property | Description |
|----------|-------------|
| `Activity` | Main way to get information from the Activity |
| `Adapter` | The channel adapter that created the activity |
| `TurnState` | The state for the turn |

## Activity Types

### Message

The most common activity type. Can include text, attachments, and suggested actions.

```csharp
agent.OnActivity(ActivityTypes.Message, async (turnContext, turnState, cancellationToken) =>
{
    var userMessage = turnContext.Activity.Text;
    var response = $"you said: {userMessage}";
    await turnContext.SendActivityAsync(MessageFactory.Text(response), cancellationToken);
});
```

### ConversationUpdate

Notifies your agent when members join or leave a conversation (supported by Microsoft Teams).

```csharp
agent.OnActivity(ActivityTypes.ConversationUpdate, async (turnContext, turnState, cancellationToken) =>
{
    var membersAdded = turnContext.Activity.MembersAdded;
    if (membersAdded != null)
    {
        foreach (var member in membersAdded)
        {
            if (member.Id != turnContext.Activity.Recipient.Id)
            {
                await turnContext.SendActivityAsync(
                    MessageFactory.Text($"Welcome {member.Name}!"), cancellationToken);
            }
        }
    }
});
```

### Event

Custom events allowing channels to send structured data to your agent.

```csharp
agent.OnActivity(ActivityTypes.Event, async (turnContext, turnState, cancellationToken) =>
{
    var eventName = turnContext.Activity.Name;
    var eventValue = turnContext.Activity.Value;
    // Handle custom event (e.g., switch on eventName)
});
```

Key properties:
- `Name` — The event name/identifier from the client
- `Value` — Event payload, typically a JSON object

### Invoke

A specific activity type where a client calls an agent to perform a command or operation (not just a message). Examples include Microsoft Teams `task/fetch` and `task/submit`. Not all channels support this.

### Typing

Indicates someone is typing in a conversation. Supported in Microsoft Teams but **not** in Microsoft 365 Copilot.

```csharp
await turnContext.SendActivityAsync(
    new Activity { Type = ActivityTypes.Typing }, cancellationToken);
await Task.Delay(2000);
await turnContext.SendActivityAsync(
    MessageFactory.Text("Here is your answer..."), cancellationToken);
```

## Creating and Sending Activities

The `TurnContext` provides multiple methods for sending responses:

```csharp
agent.OnActivity(ActivityTypes.Message, async (turnContext, turnState, cancellationToken) =>
{
    // String directly
    await turnContext.SendActivityAsync("hello!", cancellationToken: cancellationToken);

    // Using MessageFactory
    await turnContext.SendActivityAsync(MessageFactory.Text("Hello"), cancellationToken);

    // Send multiple activities
    await turnContext.SendActivitiesAsync(activities, cancellationToken);
});
```

## Working with Attachments

### Receiving Attachments

```csharp
agent.OnActivity(ActivityTypes.Message, async (turnContext, turnState, cancellationToken) =>
{
    var activity = turnContext.Activity;
    if (activity.Attachments != null && activity.Attachments.Count > 0)
    {
        foreach (var attachment in activity.Attachments)
        {
            // Get metadata: attachment.ContentType, attachment.ContentUrl
            // Use the URL to securely download the attachment
        }
    }
});
```

**Important Notes:**
- Clients send authenticated `GET` requests to retrieve attachment contents
- Each adapter (Teams, OneDrive) has its own way to get data
- URLs are typically short-lived; move files to your own storage if needed

### Citations vs. Attachments

- **Attachment** — Represents message content (files, cards, images)
- **Citation** — References attachments, handled by clients via the `Entities` property

```csharp
activity.Entities.Add(new Entity { /* Citation definition */ });
```

## Channel-Specific Considerations

The SDK acts as a "Hub" allowing agents to work with multiple clients. Different channels have different capabilities.

```csharp
// Check channel source
turnContext.Activity.ChannelId

// Access channel-specific data
turnContext.Activity.ChannelData
```

### Microsoft Teams
- Supports rich Adaptive Cards with advanced features
- Supports message updates and deletions
- Channel data for Teams features (mentions, meeting info, etc.)
- Supports invoke activities for task modules

### Microsoft 365 Copilot
- Primarily focused on message activities
- Supports citations and references in responses
- Requires streaming responses
- Limited support for rich cards/adaptive cards

### WebChat / DirectLine
- HTTP protocol for agents to communicate over HTTPS
- Full support for all activity types
- Supports custom channel data

### Third Party Channels (Slack, Facebook, etc.)
- Might have limited support for certain activity types
- Card rendering might be different or unsupported
- Always check specific channel documentation
