# Adaptive Assistant – Claude Code Guidelines

## Punctuation

- Use **en dashes** (– / `&ndash;`) for ALL dash usage without exception: separators in headings, ranges, parenthetical breaks, inline asides.
- **NEVER** use em dashes (— / `&mdash;`). This applies to every piece of copy written — prose, HTML content, subject lines, everything.
- Before saving any file, grep for `—` and `&mdash;` and replace any found.
